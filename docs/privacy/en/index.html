1. Scope

This policy applies to the Intent macOS app and browser extension.

2. Data collection by the developer

Intent has no backend servers. While you use Intent, it does not upload any personal data, browsing data, settings, or usage statistics. It has no advertising or cross-site tracking, and does not sell or share user data.

3. Local processing and storage

To provide its features, Intent stores the following on your device:

  • Managed domains and display names generated from those domains
  • Per-website settings for time, number of opens, reminders, quick views, and timer modes
  • Current timer, visit, pause, and status information
  • Daily open counts, usage time, quick views, reasons for opening websites, and historical statistics
  • Interface language settings for the Safari browser extension and macOS app, a one-time welcome acknowledgment, and other interface preferences
  • If Smart Suggestions is enabled: related domains, daily counts and active time, thresholds, the most recent suggestion time, and allowlist or remind-later status

To uphold its commitment not to upload user data, Intent does not request website icons (favicons) from third-party services.

4. Website permissions

You can manage Intent's website access in your browser settings. You can allow, deny, or revoke this access in your browser at any time.

5. Smart Suggestions

Smart Suggestions is turned off by default. Whether you enable it does not affect Intent's other features. Enabling Smart Suggestions requires access to all websites for the feature to work. Intent does not collect unnecessary data or upload any data; the data it collects is stored only locally.

6. Data management

Intent manages historical usage records separately from the temporary data needed to keep its features working.

You can clear website usage records from Settings. Daily statistics for Smart Suggestions cover the most recent seven days; older data is removed during cleanup. “Clear All Data” removes website management settings, website usage records, and Smart Suggestions data, while retaining interface language settings and preferences for displaying usage instructions. Necessary internal operating state may be retained or recreated.

Temporary data is updated or cleared as features operate. If the browser cannot provide session storage, Intent temporarily stores necessary session identifiers, along with website, tab, and timer state for Smart Suggestions, in a local compatibility storage area. These compatibility records may remain locally after Safari quits. When Safari next launches, Intent updates the session identifier and clears the previous session's temporary working state for Smart Suggestions. This data is stored only locally and is not uploaded to the developer.

7. Apple platform services

Apple may process data relating to App Store downloads, purchases, system diagnostics, or other platform services under its own privacy policy. This processing is performed by Apple and is not controlled by Intent.
