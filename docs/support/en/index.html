A few things to try first

Start here for common extension issues.

Intent isn't running?

Open your browser settings, choose Extensions, and make sure Intent is enabled. Then return to the page and try again.

Can't find Intent in the toolbar?

Customize your browser toolbar and add Intent. Menu names may vary by browser; some browsers also let you pin the icon from the Extensions menu.

A managed website isn't responding?

Check Intent's access to that website in your browser settings. Make sure access is allowed for the website you want to manage, then reload the page.
